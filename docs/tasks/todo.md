### 重构中发现并修掉的三个问题

1. **决策笔记取号命令是坏的** —— 第一版 `grep -oE '^[0-9]{4}-[0-9]{4}' | cut -d- -f2` 在 `2026-09-27-0001-xxx.md` 上返回空。纸面规则与实际不符比没有规则更糟，已改为 `-f4` 并实测。
2. **`node` 不在 PATH 上** —— AGENTS.md 初稿全用裸 `node`，命令会直接失败。已加「零、Node 解释器」一节定义 `$NODE`，全文命令改为 `$NODE`，并照抄跑通了全仓门禁。
3. **移动插件目录会让插件从 boot graph 里消失** —— 见下。

### 第 3 条的诊断与处置

`ClientModuleRegistry.pkgMeta` 按「模块 specifier + 解析基准」缓存包元数据，**无条件命中**且注释明确写着负面判定稳定到重启为止（`packages/client/modules/src/index.ts:560-562, 781-784`）。包名没变而磁盘路径变了，缓存里仍是旧的 `clientPath`，于是该行无法重组进 boot graph。

诊断方式：把旧路径临时补回（符号链接），插件立即重新出现在 graph 中（rev `76846d174d99`），产物逐字节正确 → 证明卡点就是这份缓存。

处置：**拆掉临时符号链接，要求重启**。根因是内存缓存，正确解是重启进程；留一个违反本仓库目录规则的符号链接属于贴临时补丁。诊断得到证实后，临时链接已移除。
