# 任务动态复用侧栏面板行加浮层

状态：implemented
类别：feature
日期：2026-11-05
插件：session-activity

## 背景

需求是在侧栏「新会话」按钮下方加一个入口，点开向右展示「正在运行 / 运行结束但还没查看」的会话，点击跳转对应会话，并支持默认展开或点击才展开。

DSH 的侧栏里，「新会话」下方唯一已分配空间的扩展位是 `sidebar.panellist`：每个 entry 被 `ui-sidebar` 包成一个按钮，点击默认 `selectPanel(id)` 切换主面板。浮层没有专属席位；`shell.overlay` 是框架级浮层（本身 click-through，条目可自行接管指针事件）。同时，客户端插件拿不到 profile 里插件行的 `config`。

## 决策

- 侧栏入口注册到 `sidebar.panellist`，`id: session-activity`、`order: -10`，排在「插件」等行之前即「新会话」正下方。
- glyph 挂载时找到外层按钮，挂一个原生 click 监听并 `stopPropagation`，把点击改成浮层开关，不走 `selectPanel`；同时维护 `aria-haspopup` / `aria-expanded`。
- 浮层在 `shell.overlay` 里挂载，内容用 `react-dom` portal 到 `document.body`（`z-index: 200`），按侧栏按钮的 rect 固定定位到右侧；点外部、Esc、再点侧栏行关闭。
- 可访问性：侧栏行 `aria-label` 带任务数，`aria-haspopup` / `aria-expanded` / `aria-controls` 指向浮层；Esc/关闭按钮关闭后焦点回到侧栏行。
- `layout.selectPanel` 对未注册的主面板 key 会抛错，而「更多」菜单是否列出 panel entry 由 `sidebar.panellist.actions` 的注册者决定。所以再注册一个空的 `main` 占位（key `session-activity`）：它被渲染时把主面板退回 `conversation` 并展开浮层。这也兜住 glyph 监听失效的点击路径。
- 三个席位都用 `ctx.slots.inject` 绑定到 slot 声明生命周期；某席位缺失/晚声明时其余注册仍然成立。
- 数据取 `sessions.list` + `uiSession.sessionStatus`（`running`、`completionUnread`）+ `uiSession.adapter.current`；运行中优先，组内按 `updatedAt` 降序；跳过空白会话与 `origin === 'subagent'` 的子会话。
- 「默认展开」是浮层底部的开关，持久化在 localStorage 的 `dsh.session-activity.default-open`；首次默认关闭（点击才展开），开启后进入应用且有任务时自动展开。
- 筛选/排序/状态机放在 `src/model.js`，构建时内联进经典脚本产物；测试直接 import，不必在 VM 里搭 React。

## 理由

- `sidebar.panellist` 是「新会话下方」唯一有布局位置和主题样式的席位；另起一个浮层按钮只能靠猜坐标，会和面板行重叠。
- 需求要的是贴在侧栏旁的小列表，不是整页切换，所以主面板只留空占位，不用它承载内容。
- `shell.overlay` 不会被侧栏的滚动容器裁切，是浮层的合理挂载点；但 0.2.2 的窄窗 drawer 把遮罩放 70、侧栏放 71，而 overlay 层只有 20——留在层里会被遮罩盖住。所以内容 portal 到 `body`，`z-index: 200`，只有挂载仍借 overlay。
- `slots.inject` 把每个席位绑到声明生命周期，比直接 `register` 更能承受组合差异与重声明。
- `completionUnread` 的语义就是「停在你没看的地方」：会话进入主视图（`retainedBy.mainView > 0`）时清除，所以点击跳转即完成「已查看」，不需要额外的已读状态。
- 客户端插件不能读行配置（client-modules 建 entry 时只传 name），偏好只能落在浏览器侧；localStorage 足够表达「默认展开」。
- 复用侧栏行的代价是语义借用：该 entry 理论上指向一个主面板。用最小的 DOM 接触（只找最近的外层按钮、只接管 click）换到正好的位置，并把风险写进测试与 README。
- `main` 占位是必需项而不是可选补丁：`LayoutController.selectPanel` 先检查主面板注册表，未注册直接抛错；没有占位，任何直接选中本 id 的路径都会既没反应又留一条控制台错误。
- 占位只做「退回会话 + 打开浮层」，不渲染页面；需求要的是侧栏旁列表，不是第二个任务页。

## 替代方案

| 方案 | 放弃原因 |
| --- | --- |
| 注册 `main` 主面板 + panellist 行，点击打开整页任务列表 | 需求要的是侧栏旁展开的列表，整页切换会打断当前会话；观感也不对。 |
| 替换整个 `sidebar` 席位，自己画侧栏 | 会 shadow 掉内置导航列（品牌行、新会话、面板行、工作区浏览、设置脚注），上游一改就全坏。 |
| 只用 `shell.overlay` 渲染一个浮动按钮 | 没有已分配空间，靠固定坐标猜位置会压住「插件」行；侧栏折叠/缩放后更难对齐。 |
| 把浮层留在 `shell.overlay` 里（不 portal） | 窄窗 drawer 的遮罩/侧栏是 z 70/71，overlay 只有 20，浮层会被压在遮罩后面。 |
| 直接 `ctx.slots.register` 三个席位 | 任一席位未声明会让 apply 抛错，后续注册全部丢失；`slots.inject` 按声明生命周期各自成立。 |
| 不注册 `shell.overlay`，直接从侧栏 glyph portal 出浮层 | 浮层生命周期会绑在侧栏行上（折叠/卸载随之移除），也没有统一的常驻挂载点；本插件让 overlay 只做挂载，内容仍 portal 到 body。 |
| 把入口放到 `sidebar.workspaces.directoryFlow` | 该席位只在「添加工作区」目录流程打开时渲染，不是常驻区域。 |
| 用 DOM 插入在「新会话」按钮后塞一个自己的行 | 直接改内置导航列的 DOM，比接管一个面板行的 click 更脆，也没有主题样式可继承。 |
| 用插件行 `config` 控制默认展开 | 客户端插件拿不到行配置；Host 半区无法把值传给浏览器半区而不引入自建桥。 |
| 在服务端记录「已查看」/展开偏好 | 需要 Host 半区与持久化设施，收益只是一个浏览器偏好，过重。 |

## 影响

- 依赖 `ui-sidebar` 的 PanelRow 结构：按钮包住 glyph、点击走 `selectPanel(id)`。上游改动会让点击落到 `main` 占位（仍会打开浮层，但闪一下主面板）；`test/contract.test.mjs` 会在源码形状变化时先失败提醒。
- 默认展开偏好只存在当前浏览器 localStorage；换设备或清缓存回到点击展开。
- 默认展开只在有任务时生效，避免每次启动弹一个空浮层。
- 浮层位置依赖 DOM 测量；侧栏折叠/窗口缩放通过 `ResizeObserver` + `resize` 重算，测量失败时退化为 `(8, 8)` 起点。
- portal 的 `z-index: 200` 依赖抽屉/遮罩层级保持在 70/71 附近。
- 没有 Host 半区，真实页面渲染（行位置、贴边、深浅色、窄窗 drawer）仍需现场确认。
- 关闭时只在 Esc / 关闭按钮路径归还焦点；点浮层外关闭不抢焦点（避免打断用户正在点的另一个控件）。
