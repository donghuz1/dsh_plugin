# Qoder 设计取值与证据分级

本插件每个色值的来源与可信程度。**只描述当前采用的取值**；推导过程留在本次调研的方法说明里。

## 证据分级

| 级别 | 含义 | 本插件中的用例 |
| --- | --- | --- |
| **[V]** 已验证 | 取自 Qoder 官网 CSS token 原文、官方文档源码，或截图像素采样 | 暗色色阶、语义色、边框、圆角刻度、动效曲线 |
| **[D]** 推导 | 由官方 CSS 的 fallback 值或 `color-mix` 表达式计算得出 | 部分 hover/active 取值 |
| **[E]** 估算 | 仅由截图推算或跨版本外推 | 亮色模式的表面角色映射 |

## 取证方法

Qoder 桌面端是闭源 Electron 应用，未安装也未反编译。客户端界面色值来自官方文档配图与第三方评测截图的像素采样，配合官网 CSS token 的语义映射。

`web_fetch` 无法访问 qoder.com（DNS 解析到非公网 IP，被工具拒绝），改用 `curl` 取源。

关键突破是 qoder.com 的 CSS 在 CDN 上留有完整的 Ant Design 风格 token 系统——241 个 `--ant-*` 变量，含 `:root` 暗色与 `[data-theme=light]` 亮色两套，全部为原始文本而非估算。

## 两套绿色

Qoder 存在两套绿色，用错会「不像 Qoder」：

| 场景 | 色值 | 证据 |
| --- | --- | --- |
| **IDE 客户端主色（本插件采用）** | `#27bd51` | 官方文档 Markdown 源码 4 处 `<Card color="#27BD51" />`；CSS fallback `#2adb5c`；5 张截图像素 `#26b440` |
| 官网主色（暗） | `#6ad86c` | `:root{--ant-color-primary}` |
| 官网主色（亮） | `#80c776` | `[data-theme=light]` |

HSL 分析证实二者色相差 10°（131° vs 121°），不是压缩误差：官网绿更灰更淡偏黄，IDE 绿更饱和偏青。

## 暗色双色调

Qoder 暗色不是单一暖调，这一点与「暖色主题」的直觉相反：

| 区域 | 色相 | 取值 |
| --- | --- | --- |
| chrome（侧栏 / 标题栏）· 编辑器画布 | 偏冷蓝 H≈210–220° | `#1a1b1c` · `#0f1012` |
| 容器 / 菜单 / 文字 | 偏暖黄 H≈45–60° | `#171716` · `#1a1a17` · `#2a2926` · `#eeeeeb` |

饱和度普遍只有 2–8%，是极克制的偏移。色阶按此双色调逐级指派，未做统一的暖调旋转。

另一处反直觉特征：**侧栏比内容区更亮**（`#1a1b1c` vs `#0f1012`），与 VS Code 相反。

## 暗色取值

| 角色 | 取值 | 级别 |
| --- | --- | --- |
| 应用底 / 内容区 | `#0f1012` | [V] |
| 侧栏 / chrome | `#1a1b1c` | [V] |
| 浮层 / 容器 | `#171716` · `#1f1f1c` | [V] |
| 边框（发丝 / 默认） | `#1d1d1b` · `#2a2926` | [V] |
| 文字 primary / secondary / tertiary | `#eeeeeb` · `#959590` · `#7b7b76` | [V] |
| success / warning / error / info | `#82b591` · `#e5b357` · `#db655c` · `#4d7fe2` | [V] |
| 链接 | `#87d578` | [V] |
| 主按钮文字 | `#171716` | [V] |

## 亮色取值

亮色沿用同一套角色关系，取值来自 `[data-theme=light]` token 原文，但**客户端亮色态无真实截图**，表面角色映射属 [E]。两处刻意偏离见 README。

## 未采用

- **官网暖色中性**：官网暗色偏暖（`#0f0d0c` · `#171716` · `#2a2926` · `#484743`），与 IDE chrome 的冷蓝不同，混用会失真。
- **`@design-llm/qoder-design` npm 包**：第三方复刻库，非官方，色值与官网存在明显差异，仅作旁证。
- **`qoder-design` npm 包**：实为 mermaid 依赖，与设计系统无关。
- **品牌辉光与玻璃拟态**：官网营销页元素，非 IDE 内组件。
